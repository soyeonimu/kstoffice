웨딩홀 견적 계산기

더파티움 여의도 · 상담실장이 제안한 금액을 입력하면 수지타산이 바로 계산돼요.

① 상담실장 제안 입력

입력 내용은 현재 기기의 브라우저에 자동 저장됩니다. 다른 휴대폰이나 시크릿 모드에는 공유되지 않아요.

기본 축의금은 1인당 10만원입니다. 보증인원이 더 많으면 보증인원 기준으로 식대를 계산합니다.

저장한 날짜별 견적

저장된 견적이 없어요.

축의금 양가 분리 계산 (선택)

기본 모드에서는 위의 전체 평균 축의금과 납부 인원을 사용합니다. 양가 분리 계산 시 양가의 납부 인원 합계와 실제 하객 수가 달라도 입력한 값으로 계산합니다.

할인 전후 비교 (선택)

② 기타 예상 비용 (선택 입력)

모두 기본 0원입니다. 견적에 이미 포함된 항목은 0원으로 두세요. 더파티움의 필수 추가요금으로 확인된 금액은 아닙니다.

식대·대관료에 부가세가 포함됐는지, 생화장식과 본식사진이 어느 범위까지 포함되는지 계약서에서 반드시 확인하세요. 누락된 세금이나 필수 추가금만 별도로 입력하세요.

계약 전에 꼭 확인

당일 계약 혜택도 최종 견적에 반영한 금액으로 확인하고, 계약금·취소·변경 규정은 서면으로 받아두세요.

개인용 비연결 페이지입니다. 홈페이지 메뉴에 노출하지 않고 검색 제외를 요청하지만, 공개 GitHub Pages이므로 완전한 비공개 페이지는 아닙니다. 민감한 정보는 입력하지 마세요. 계산은 브라우저 안에서만 진행됩니다.
